 WeatherNow

Aplicação web de previsão do tempo desenvolvida com Python, Flask, HTML, CSS e JavaScript.

 Demonstração:

![Tela inicial do WeatherNow](<img width="1894" height="988" alt="Captura de tela 2026-10-13 190943" src="https://github.com/user-attachments/assets/ea000f8f-5536-4b72-83e1-66e155501431" />
)

 Funcionalidades:

- Busca de cidades
- Temperatura atual e sensação térmica
- Umidade, vento e precipitação
- Previsão por hora
- Previsão para os próximos dias

 Tecnologias:

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Open-Meteo API
